# AI 홈 CCTV 자율 보안관제 앱

## BRB-C01
홈 CCTV를 사용하는 사람이 네트워크 트래픽의 보안 상태를 확인할 때, 이 앱이 논문에서 제안한 위험도 점수와 0.5 임계값을 이용해 정상 또는 악성 트래픽을 판별하고 위험한 트래픽의 자율 차단 결과를 보여준다.

## BRB-C02
사용자가 실제로 할 일:
1. 정상 데이터 또는 악성 데이터를 입력한다.
2. 분석하기를 눌러 위험도와 판정을 확인한다.
3. 잘못된 데이터를 입력하여 앱이 멈추지 않는지 확인한다.

## BRB-C03
첫 화면에 논문 제목과 앱이 누구를 어떻게 돕는지 설명이 있습니다.

## BRB-C04
논문의 0.50 임계값을 실제 판정에 사용하며, 논문에 기록된 실험 결과(0.082, 0.841, 0.759, F1 0.981)를 별도로 표시합니다.

## BRB-C05
세 단계 사용법이 첫 화면에 있고 입력 오류를 예외 처리합니다.

## BRB-C06
실제 개인정보를 사용하지 않습니다. 모든 입력 예시는 가상 데이터입니다.

## BRB-C07
API 키와 같은 비밀값이 없으며 외부 API를 호출하지 않습니다.

## 실행
`index.html`을 브라우저에서 열면 바로 실행됩니다. 설치/로그인/서버가 필요하지 않습니다.

## 주의
브라우저의 체험용 위험도 계산은 논문의 네트워크 특징(패킷 크기, 빈도, 간격, 연결 수)을 반영한 시뮬레이션입니다. 실제 CCTV 네트워크를 차단하지 않습니다. 논문에 기재된 실험 수치는 제출 전에 원 실험 로그/코드와 대조해야 합니다.
